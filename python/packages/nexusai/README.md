# NexusAI Python SDK

Install directly from this repository:

```bash
pip install git+https://github.com/onenexus-team/onenexus-sdks.git#subdirectory=python/packages/nexusai
```

Login:

```bash
nexusai login --url http://165.245.166.16:30210
```

Upload an existing dataset folder:

```bash
nexusai DataHub UploadToDataset --dataset-id <your-dataset-id> --source-path <path-to-dataset-folder>
```
